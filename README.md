# This plugin helps combat admin abuse on Minecraft servers.

## Use the /abusegui command to view game mode changes for all players.

## Operators must justify all game mode changes (except for Survival mode).

## [Paper](https://fill-ui.papermc.io/projects/paper/family/1.21) and [Minecraft](https://www.minecraft.net/download/server) 1.21x are required
